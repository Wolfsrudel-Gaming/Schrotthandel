# Schrotthandel (wr_scrap)

Hardcore-RP-Schrottplatz für **ESX Legacy**: Fahrzeuge realistisch zerlegen,
Materialien sortieren, schreddern, pressen und einschmelzen, Kräne und LKW fahren,
einen spielergeführten Recyclingbetrieb führen und auf der illegalen Seite
Autos ausschlachten, VINs fälschen und aus Teilen neu zusammenbauen.

Kein "E drücken und warten": Jede Tätigkeit ist echtes Handwerk mit Werkzeug,
Animation und eigenem Minigame.

> **Status:** Konzeptphase abgeschlossen, Umsetzung startet mit dem Fundament.
> Fortschritt siehe [Roadmap](docs/ROADMAP.md).
